# willyhorizont-sublimetext-plugin  

## Sublimetext with VS Code feel | Sublimetext vscode-ify | vscode keyboard shortcut or keybinding in Sublimetext  

[  
    "ctrl+`",  
    "ctrl+alt+up",  
    "ctrl+alt+down",  
    "ctrl+shift+up",  
    "ctrl+shift+down",  
    "alt+up",  
    "alt+down",  
    "shift+alt+up",  
    "shift+alt+down",  
].map((k) => ("vscode keyboard shortcut or keybinding " + k + " in Sublimetext")).join("\n")  

## Installation  
```
cd ~/.config/sublime-text/Packages/User
git remote set-url origin https://github.com/willyhorizont/willyhorizont-sublimetext-plugin.git
git fetch origin
git reset --hard origin/main  
```
